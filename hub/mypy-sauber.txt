# Module, deren Typprüfung sauber sein MUSS.
#
# `mypy homepilot` meldet in einem gewachsenen Projekt viel - 213 Fehler
# in 48 Dateien, als diese Liste entstand. Deshalb stand die Prüfung
# jahrelang auf «darf rot sein», und damit las sie niemand: Eine Zahl,
# die immer rot ist, ist keine Auskunft.
#
# Also andersherum. Was heute sauber ist, steht hier drin und wird
# geprüft; der Rest bleibt aussen vor, bis ihn jemand aufräumt. Die
# Liste kann nur wachsen - `python3 tools/mypy_sauber.py --ergaenzen`
# nimmt auf, was inzwischen sauber ist, und der Prüflauf wird rot,
# sobald ein Modul von hier wieder Fehler meldet.
#
# Neue Dateien gehören hierher, sobald sie sauber sind - und das sind
# sie meistens an dem Tag, an dem sie entstehen.
